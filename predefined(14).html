1. String Functions

JavaScript provides many built-in String methods (functions) to manipulate and work with text.

text.length – Returns the number of characters in a string.

text.toUpperCase() – Converts the string to uppercase.

text.toLowerCase() – Converts the string to lowercase.

text.trim() – Removes spaces from the beginning and end.

text.charAt(6) – Returns the character at index 6.

text.indexOf("world") – Returns the position of "w" in the string.

text.replace("world", "hi") – Replaces "world" with "hi".

text.slice(1, 5) – Extracts characters from index 1 to 4.

text.concat(" is awesome!") – Joins another string to the end.

2. Math Functions

JavaScript provides a built-in Math object with many useful mathematical functions for calculations..

Math.PI – Returns the value of π (3.14159).

Math.sqrt(25) – Returns the square root of 25.

Math.pow(2, 3) – Returns 2 raised to the power of 3.

Math.abs(-10) – Returns the absolute value (10).

Math.ceil(4.3) – Rounds up to the nearest integer.

Math.floor(4.9) – Rounds down to the nearest integer.

Math.round(4.5) – Rounds to the nearest integer.

Math.random() – Generates a random decimal between 0 and 1.

Math.max(10, 20, 30) – Returns the largest number (30).

Math.min(10, 20, 30) – Returns the smallest number (10).
